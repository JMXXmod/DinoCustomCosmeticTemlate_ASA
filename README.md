# DinoCustomCosmeticTemlate_ASA
Small template for creating a custom cosmetic for your dinosaurs

If you want to change the mesh, you obviously need to replace the reindeer mesh with the one you want.

If you want to change which dinosaur the skin is for, make sure to change the tag 'Equip Requires Explicit Owner Tags' in the primalitem to the tag of the new dino.

If you want a skin that can be applied to any dinosaur, simply delete 'Equip Requires Explicit Owner Tags'.
